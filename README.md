# Arkitektens vardag i en decentraliserad myndighet

Författare: Erland Lindmark

Detta är ett startpaket för en svensk lärobok/handbok om styrning, kvalitetssäkring och samordning av arkitektur i en större statlig myndighet med decentraliserade utvecklingsområden och agil omställning.

## Syfte

Boken ska hjälpa IT-arkitekter att utveckla förståelse för vad arkitekturarbete handlar om i praktiken, varför kvalitetssäkring och samordning är viktiga, och hur de kan genomföras på ett sätt som stödjer utveckling snarare än bromsar den.
